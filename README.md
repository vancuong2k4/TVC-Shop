## 🛠️ Kiến Trúc Công Nghệ (Tech Stack)

### Frontend
- **Framework**: [React 18](https://reactjs.org/) + [Vite 5](https://vitejs.dev/) (Tốc độ bundle siêu tốc).
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/) + Custom Glassmorphism Utilities.
- **Icons & Visuals**: [Lucide React](https://lucide.dev/) (Hơn 100+ icon vector tinh tế).
- **State Management**: React Context API (`AuthContext`, `CartContext`, `CurrencyContext`, `RecentlyViewedContext`).
- **Multi-Currency Engine**: Hỗ trợ chuyển đổi tức thì VND, USD, EUR, JPY, GBP với tỷ giá thời gian thực.

### Backend
- **Framework**: [Laravel 8.x](https://laravel.com/) RESTful API.
- **Authentication**: Laravel Sanctum / Token-based Session & Google OAuth 2.0.
- **Database**: MySQL / MariaDB (Hỗ trợ Postgres).
- **AI Engine**: Google Gemini API Integration (`gemini-flash`).

## 🚀 Hướng Dẫn Cài Đặt & Khởi Chạy (Quickstart Guide)

### 1. Yêu cầu môi trường
- **PHP** >= 8.0 & **Composer**
- **Node.js** >= 18.x & **npm**
- **MySQL** (hoặc XAMPP / WampServer)

### 2. Cài đặt Backend (Laravel)
```bash
# 1. Di chuyển vào thư mục backend
cd laravel-backend

# 2. Cài đặt thư viện PHP
composer install

# 3. Tạo file cấu hình môi trường
cp .env.example .env

# 4. Khởi tạo App Key
php artisan key:generate

# 5. Cấu hình Database trong file .env và chạy Migration kèm dữ liệu mẫu
php artisan migrate:fresh --seed

# 6. (Tùy chọn) Chạy server backend độc lập
php artisan serve
```

### 3. Cài đặt Frontend (React + Vite)
```bash
# 1. Mở cửa sổ terminal mới và di chuyển vào frontend
cd tvc-shop-frontend

# 2. Cài đặt dependencies
npm install

# 3. Khởi chạy máy chủ phát triển
npm run dev
```
Truy cập trình duyệt tại: `http://localhost:5173`
